Donna – AI Assistant for Work & Life

+

Donna is a context-aware AI assistant that helps users manage scheduling, email, memory, and tasks through a natural chat and voice interface. Inspired by Donna Paulsen from Suits, this assistant goes beyond conversation — it takes action.

✅ Automation Architecture: GPT-4o + n8n (self-hosted on Docker), integrated with Redis/Postgres, handles complex flow orchestration and logic routing.

✅ Full Stack Memory: Firebase (auth, usage logging) and Notion (editable task memory) support real-time interactions and editable long-term memory.

✅ Scheduling Intelligence: Custom DST-aware date parser processes natural language like "next Friday at 6pm" and creates events in Outlook.

✅ Voice & Subscription (Planned): Whisper, ElevenLabs, and Stripe-based tiered subscriptions are planned next.

✅ iOS MVP: A working SwiftUI frontend deployed to TestFlight supports calendar creation through typed input.

🔧 Tools Used: GPT-4o, n8n, Firebase, Notion API, Redis, Postgres, Docker, SwiftUI, Whisper (planned), ElevenLabs (planned)

Wisconsin Fishing Team Website

+

This project began as a class assignment and grew into a full-scale tool for the Wisconsin Fishing Team. The public-facing site provides key info: officer bios, tournament schedule, contact form, apparel shop, and gallery. For members, it enables rod/boat reservations, sponsorship access, and secure login.

Admins can edit calendars, update shop inventory, and manage content. Built using HTML, JavaScript, CSS (Bulma), and Firebase for auth, hosting, and data. Also integrates with Square for ecommerce and uses Git for version control.

SpendSmart – Android Finance App

+

SpendSmart is an Android app that helps users track expenses, identify savings, and learn smart habits. Core features include receipt scanning (via ML Kit), data categorization, and interactive charts powered by MPAndroidChart.

Users can also join community chatrooms to share deals or tips. The UI was gamified to encourage frequent use and goal setting. Built in Android Studio using Java/XML with Firebase backend and camera APIs. Targeted toward students and early professionals.

Data Olympians – Data Analytics Project

+

This team project explored Olympic history data using data science and analytics. We used Python (pandas, matplotlib), Tableau, and sentiment analysis with Twitter data to explore questions like: Which sports dominate? What are typical gold medal ages? Are medal trends region-based?

We also tested clustering models and drafted insights into athlete longevity and performance. Final report includes charts, predictive models, and discussion of missing data gaps and ethics. Available on request.
