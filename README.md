# Connor Kolb – Portfolio Website

🔗 **Live Site**: [https://connor-kolb-portfolio.web.app](https://connor-kolb-portfolio.web.app)  
📂 **GitHub Repo**: [github.com/connor-kolb-13/portfolio](https://github.com/connor-kolb-13/portfolio)

## 📄 Overview

This is my personal portfolio website showcasing my **projects**, **skills**, **work experience**, and **contact information**. It is fully responsive and built with modern web technologies including:

- HTML5, CSS3 (Bulma framework)
- JavaScript (vanilla)
- Firebase Hosting
- Git & GitHub for version control

The site is organized into multiple interactive sections including:

- **Home**: Personal branding, motto, and lifestyle visuals
- **About**: Background, education, goals, and interests
- **Skills**: Word cloud generator tied to Firebase with admin interface
- **Projects**: Accordion-based showcase of key projects with expandable details and links
- **Experience**: Work history and extracurriculars styled with Bulma media objects
- **Contact**: Responsive contact section with resume preview and downloadable PDF

## 🚀 Features

- Fully responsive (mobile, tablet, desktop)
- Admin panel for managing skill entries and word cloud
- Firebase-backed skill storage and PDF hosting
- Animated project accordion system
- Dynamic layout using Bulma CSS grid

## 🛠️ Technologies

- **Frontend**: HTML, CSS (Bulma), JavaScript  
- **Backend/Hosting**: Firebase (Hosting, Firestore, Auth)  
- **Dev Tools**: Git, VS Code, Firebase CLI  
- **Design**: Figma mockups, vector assets, and brand visuals
