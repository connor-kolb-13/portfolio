# Connor Kolb – Portfolio Website

🔗 **Live Site**: [https://connor-kolb-portfolio.web.app](https://connor-kolb-portfolio.web.app)  
📂 **GitHub Repo**: [github.com/connor-kolb-13/portfolio](https://github.com/connor-kolb-13/portfolio)

## 🎯 Purpose

This portfolio serves as a digital extension of my resume, designed to showcase my technical, strategic, and design capabilities to hiring managers, recruiters, and collaborators. It highlights my best work—from end-to-end projects to personal branding—using clean UI, responsive layouts, and interactive components. Everything here is built and maintained by me.

---

## 📄 Overview

The site is built using modern web technologies and deployed via Firebase. It is fully responsive and features a modular layout organized into interactive sections:

- **Home** – Branding statement, personal motto, and lifestyle visuals
- **About** – Education, goals, background, and interests
- **Skills** – Interactive word cloud, updated through a built-in admin panel
- **Projects** – Accordion-style showcase of detailed technical projects
- **Experience** – Work history and extracurriculars with rich formatting
- **Contact** – Resume preview, download, and direct links for phone/email

---

## 🚀 Features

- 🔁 **Fully Responsive** – Desktop, tablet, and mobile friendly layout
- 🧠 **Admin Dashboard** – Private section to manage skills and files
- 📊 **Firebase-Backed** – Word cloud and resume PDF hosted and tracked in Firebase
- 🎛️ **Modular Components** – Accordion system for clean project navigation
- 🎨 **Consistent Styling** – Uses Bulma framework + custom CSS for branding

---

## 🛠️ Technologies

- **Frontend**: HTML, CSS (Bulma), JavaScript  
- **Backend/Hosting**: Firebase (Hosting, Firestore, Auth)  
- **Dev Tools**: Git, VS Code, Firebase CLI  
- **Design**: Figma mockups, vector assets, and personal brand visuals
